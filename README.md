# AstroMosaic

Сшивка астрономических мозаик (Windows, Go + Gio GUI).

Одно изображение тоже поддерживается: откройте один файл и нажмите **«Обработать»**.
Получите результат в исходной сетке пикселей с доступом к коррекциям фона, PSF,
хроматизма и master flat. Геометрия мозаики и относительные коррекции перекрытий пропускаются.

- Раскладка плиток: по WCS, по номерам `R-C` в именах файлов/папок (как у ASIAIR) или по общим звёздам в перекрытиях.
- Привязка по звёздам с глобальной подгонкой и общей радиальной дисторсией; ручные точки для трудных пар.
- LinearFit (как в PixInsight) и выравнивание фона по перекрытиям (плоскость на плитку).
- Совмещение R и B с G по звёздам; «Карта хроматизма» показывает модель коррекции исходных плиток до или после сшивки.
- Двухполосное смешивание: фон без звёзд плавно по всему перекрытию, детали — узким швом.
- Кадрирование и поворот результата; сохранение в FITS / XISF / TIFF / PNG / JPEG (линейные данные, растяжка только для просмотра).

## Сборка

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Скрипт собирает с `-trimpath` (без него Windows Defender ложно блокирует exe как `Bearfoos.A!ml`) и проверяет, что exe запускается.

Иконка и ресурсы Windows — в `winres/` (`go-winres make` после изменения).

XISF с несколькими изображениями открывается по первой записи `Image` — основному кадру.
Дополнительные изображения, например `crop_mask` из PixInsight WBPP, не заменяют кадр
и не подмешивают свои метаданные. Авторастяжка вычисляется по исходным float-отсчётам
без предварительного округления до 12 бит. При сильном цветовом фоне отключите
«Связать каналы», чтобы нейтрализовать его независимой растяжкой каналов при просмотре.

## Карта хроматизма

Откройте одну или несколько плиток и нажмите «Карта хроматизма» в строке анализа.
Стрелки ← / → переключают плитки; колесо меняет масштаб, перетаскивание сдвигает карту.
Слева показан R относительно G, справа — B относительно G. Цвет обозначает модуль смещения
в пикселях исходника, белые стрелки — направление исправления. Длины стрелок увеличены:
24 пикселя карты соответствуют верхнему пределу цветовой шкалы. Шкала общая для каналов
текущей плитки, но может отличаться между плитками.

Это модель совмещения центров звёзд: аффинная с проверяемой радиальной добавкой;
размытие и ореолы оцениваются отдельно через PSF.
Приведены максимум смещения по полю, число звёзд после отбраковки и медианная ошибка модели
по всем измеренным соответствиям. В областях без звёзд модель экстраполируется.
При недостатке подходящих звёзд (нужно минимум 30) или для ч/б модель не показывается.
Коррекция применяется только с флажком «Совместить каналы» и максимумом не менее 0,30 px;
меньшие измеренные смещения также можно просмотреть. Анализ не меняет исходные данные,
не требует сшивки и при каждом нажатии кнопки пересчитывается по загруженным плиткам.

Разбор дальнейших коррекций: [DISTORTIONS.md](DISTORTIONS.md).

## Геометрия SIP и диагностика поля

SIP из FITS/XISF применяется автоматически: полиномы A/B порядка 2–9 относительно CRPIX,
с учётом направления строк FITS. Обратное преобразование решается численно; AP/BP не нужны.
SIP участвует в WCS-привязке, глобальной подгонке и отрисовке без предварительного пересэмплирования.
На плитке с SIP эмпирическая k1 повторно не применяется. Некорректный или неподдерживаемый SIP
отключает WCS-привязку этой плитки; сообщение об этом появляется в итоговом статусе.
Полиномы также распознаются без суффикса `-SIP`, если присутствуют A_ORDER/B_ORDER.
Если у первой опорной плитки есть корректная WCS TAN, остальные плитки с подходящей WCS
перепроецируются в её общую идеальную TAN-плоскость. Изменение плоскости учитывается при
поиске звёзд, глобальной подгонке и отрисовке, после коррекции SIP или эмпирической оптики.
Повторного промежуточного пересэмплирования нет. Для плиток без WCS остаётся привязка
по звёздам/точкам; если WCS нет у опорной плитки, используется прежний конвейер целиком.
Явно заданные проекции, отличные от RA/DEC TAN, не интерпретируются как TAN.
Плитка, выходящая за переднюю полусферу общей TAN-плоскости, в неё не переводится.

После сшивки нажмите «Диагностика поля». Снимок последней сшивки содержит по каждой плитке:

- Сетку 4×4 с RMS принятых соответствий, средними dx/dy и увеличенными стрелками.
  RMS ячейки измеряется в пикселях исходной плитки, общий RMS — в пикселях мозаики.
  Стрелки направлены к положению звезды на другой плитке: 20 пикселей карты на 1 пиксель
  смещения, длина ограничена 24 пикселями карты. Это диагностика, а не дополнительная коррекция.
- Медианные FWHM и эллиптичность звёзд. Используется гауссова аппроксимация ядра
  в зелёном канале RGB или в ч/б; насыщенные, слабые и плохо аппроксимируемые звёзды отбрасываются.
  FWHM — геометрическое среднее большой и малой осей, e = 1 − малая/большая ось.
  Для профиля Moffat или сложной комы это оценка ядра, а не полная модель PSF.
- При ≥60 исходных соответствиях — проверку на каждой пятой группе одной звезды:
  все её наблюдения в разных плитках остаются вместе. Отдельная подгонка использует
  остальные группы, а RMS считается по отложенным соответствиям без их
  отбраковки по итоговой модели. В итоговой сшивке используются все принятые соответствия.
  Проверка оценивает модель после поиска соответствий; она не проверяет сам поиск пар.
- Сравнение простой k1 и расширенной общей модели k1+k2+p1+p2. Последняя проверяется
  только при ≥200 обучающих соответствиях с участием плиток без SIP, участии ≥2 таких плиток, покрытии ≥8 ячеек
  сетки 4×4 и достаточном диапазоне радиусов. Она принимается, если на отложенных данных
  RMS уменьшается минимум на 10% и 0,05 px. После выбора параметры уточняются на всех
  принятых соответствиях; результат должен улучшать и итоговую подгонку.
  Коэффициенты ограничены: |k1|, |k2| < 0,049; |p1|, |p2| < 0,0196. Решения у границ
  диапазона отклоняются. На плитках с SIP эта эмпирическая модель не применяется.
  Диагностика показывает сравнение ошибок и решение о применении модели.

`NO DATA` означает отсутствие измерений в ячейке. Пустые области не интерполируются;
по одним перекрытиям нельзя оценить геометрию всей площади. Статистика соответствует
последней сшивке, даже если после неё менялись загруженные плитки. Для обновления сшейте заново.

## Разная резкость плиток и каналов

В строке анализа есть флажок **«Согласовать резкость»**, по умолчанию выключенный.
Включите его перед сшивкой; если результат уже построен, переключение пересшивает мозаику.
Режим сглаживает более резкие плитки/каналы до общей ширины гауссова ядра звёзд.
Он влияет на сохраняемые линейные данные результата, исходные плитки остаются неизменными.

Ширина оценивается отдельно в каждом канале и переводится в пиксели мозаики с учётом
локального масштаба геометрического преобразования. Цель — наибольшая из медианных
ширин каналов всех плиток. У более резких каналов добавляется нормированное положительное
гауссово сглаживание; уже достаточно широкие каналы не сглаживаются.
Операция выполняется после регистрации и до LinearFit, выравнивания фона и смешивания.

Для каждого канала нужны ≥30 подходящих звёзд и ≥4 ячеек сетки 4×4 с ≥3 измерениями.
Сильная вытянутость (медианная e > 0,25), разброс медиан ширины между ячейками >35%
или слишком широкое ядро отключают согласование для всей сшивки с объяснением причины.
После пробы звёзды измеряются повторно: отклонение от общей цели не должно превышать
максимум из 0,15 px и 8%. Если проверка не прошла хотя бы для одного канала, вся сшивка
использует исходные несглаженные изображения. Кроме того, проба должна уменьшить разброс
ширины каналов минимум на 15% либо привести его к ≤0,15 px. При различии <0,1 px или требуемом
σ сглаживания <0,35 px канал остаётся без изменений.

В «Диагностике поля» показаны ширины до/после, σ сглаживания в пикселях исходника
и число звёзд по каналам выбранной плитки. Карта FWHM по сетке показывает состояние
до согласования. Нулевые границы и нечисловые отсчёты исключаются из свёртки;
на их месте сохраняется ноль, у соседних пикселей ядро перенормируется.
Отрицательные линейные отсчёты сохраняются, обрезки по диапазону 0…1 нет.

Это согласование ширины гауссова ядра, а не полное совпадение PSF и её крыльев.
Оно не восстанавливает утраченную резкость, не исправляет кому/астигматизм и не заменяет
пространственно переменную PSF или деконволюцию. Финальное геометрическое пересэмплирование
также может немного менять профиль звёзд.

## Деконволюция результата

После сшивки нажмите **«Деконволюция…»** в строке анализа. Откроется отдельный экран
с автоматически рассчитанной пробой до 768×768 px. Без рамки выбирается область со звёздами;
если на результате нарисована рамка, используется её центр. Рамка задаёт центр пробы,
а не область последующего применения. Проба рассчитывается с дополнительным полем вокруг
видимого участка, чтобы её центральная часть соответствовала обработке целого изображения.
Слева показан исходник, справа — проба с общей растяжкой. Колесо и перетаскивание работают
в каждом окне. Исходный результат на этом шаге не изменяется.

По умолчанию: 5 итераций и 35% оценённой ширины PSF. Кнопки циклически выбирают
3/5/8/12 итераций и 35/50/65% PSF; после изменения нажмите «Пересчитать пробу».
35% — более мягкое восстановление, 50/65% — более сильное. Это размер ядра деконволюции
как доля оценённого гауссова ядра, а не процент гарантированно восстановленных деталей.

Используется демпфированная Richardson–Lucy с ограниченным числом итераций, подавлением
поправок ниже оценки шума, ограничением шага и плавной маской сильного сигнала. PSF оценивается
по звёздам линейного результата. В RGB обрабатывается общая яркость (среднее R/G/B),
после чего один и тот же множитель переносится в каждый канал: попиксельные соотношения
цветов сохраняются с точностью float32. В ч/б обрабатывается единственный канал.

Края, пустые и неположительные отсчёты, насыщенные звёзды и их окружение защищены.
Маска насыщения общая для RGB. Пропущенные пиксели исключаются из нормированной свёртки;
обратная свёртка учитывает ту же нормировку. Нечисловые отсчёты в результате заменяются нулём.
Линейный результат не обрезается по диапазону 0…1; защищённые отрицательные отсчёты сохраняются.

Кнопка «Применить ко всему результату» доступна только для свежей пробы, прошедшей проверки:

- В каждом канале измерено минимум 10 несатурированных звёзд до/после.
- Медианная ширина ядра уменьшилась минимум на 2%, но не более чем на 35%.
- Медианное изменение центров не превышает 0,15 px.
- Медианное изменение апертурного потока не превышает 5%.
- Оценка фонового шума не выросла более чем на 20% (с малым абсолютным допуском).

После применения проверки повторяются на всём результате. Если они не прошли,
исходный результат сохраняется. Успешную операцию можно отменить кнопкой «Отменить»
во вкладке результата; хранятся последние три шага геометрии/восстановления.
Отчёт показывает FWHM, изменение оценки шума и апертурного потока по каналам.
Изменение фотометрии может быть ненулевым даже у прошедшей проверку операции.

Режим «общая круглая» ограничен почти круглыми, достаточно однородными гауссовыми ядрами с FWHM
2…10 px. Требования к числу звёзд, покрытию и однородности такие же, как у согласования
резкости. Это частичное восстановление гауссова размытия, а не полная коррекция комы,
астигматизма, дискового дефокуса или крыльев Moffat. Локальная эллиптическая модель
описана ниже; отдельные цветовые PSF и эмпирические профили выбираются дополнительными режимами.

## Локальная эллиптическая PSF

На экране деконволюции переключите **«PSF: общая круглая» → «PSF: локальная эллиптическая»**
и нажмите «Пересчитать пробу». По умолчанию сохраняется прежний общий режим.
Локальный режим описывает изменение ширины, вытянутости и направления почти гауссовых
ядер по полю. Он может уменьшать симметричную вытянутость при слабом смазе и
астигматизмоподобных профилях; асимметричная кома и сложные негауссовы профили остаются вне модели.

На всё исходное изображение строится сетка 4×4. В ячейке нужно ≥5 подходящих звёзд;
необходимы ≥4 измеренные ячейки в ≥2 рядах и ≥2 столбцах. Отбрасываются плохо описываемые
гауссианом и сильно асимметричные звёзды, ядра с e >0,5, малой осью FWHM <1,5 px или большой
осью >10 px. При робастном разбросе ширины внутри ячейки >20% её модель не используется.
Ковариации оцениваются медианами и интерполируются между измеренными узлами; углы
не усредняются напрямую, поэтому переход через ±90° не создаёт скачка ориентации.

«Карта PSF» показывает источник модели до обработки: число звёзд, FWHM двух осей,
эллиптичность и угол. Эллипсы FWHM увеличены ×6; цвет кодирует эквивалентный FWHM
2…10 px. `NO MODEL` означает отсутствие надёжного измерения. В такой ячейке исходные
пиксели сохраняются; обработка соседних измеренных ячеек плавно ослабевает к границе.
Карта поддерживает масштабирование и сдвиг. Повторное нажатие возвращает пробу до/после.

Обработка локально стационарная: пересекающиеся участки используют интерполированное
эллиптическое ядро и затем плавно смешиваются. Это аппроксимация поля PSF, а не единая
глобальная Richardson–Lucy с произвольным пространственно переменным оператором.
Фиксированная сетка участков и достаточное окружение одинаковы у пробы и полной операции.
Режим обычно медленнее общей PSF; при полном применении показан номер обрабатываемого участка.

Параметр «Сила» регулирует снятие размытия: одинаковая во всех направлениях составляющая
следует прежнему правилу квадратов, избыточная направленная составляющая снимается сильнее.
В RGB по-прежнему обрабатывается общая яркость с сохранением попиксельных соотношений цветов.
Проверки FWHM, потока, центров и шума выполняются на звёздах измеренного покрытия.
Дополнительно в каждой контрольной ячейке с ≥5 звёздами FWHM должен уменьшиться ≥1%,
эллиптичность не должна вырасти более чем на 0,03; при исходной e ≥0,15 требуется её
уменьшение ≥2%. Проверяется и локальный фон: рост оценки шума ≤20% с малым абсолютным допуском.
При неудачной проверке применение отменяется целиком. Успешную операцию можно отменить обычной кнопкой.

## Асимметричная кома

В «Деконволюция…» переключите режим на **«PSF: асимметричная кома»** и пересчитайте пробу.
Для каждого узла сетки 4×4 складываются изображения минимум 12 изолированных ненасыщенных
звёзд. Эмпирическое ядро 17×17 px сохраняет направление хвоста; симметризация не применяется.
Ячейка принимается при асимметрии ≥0,04 и уменьшении ошибки на отложенной трети звёзд
минимум на 5% относительно симметризованного профиля. Нужно ≥4 ячеек в ≥2 рядах и столбцах.
Если асимметрия не подтверждена, программа сообщает об этом и не подменяет её эллипсом.

«Карта PSF» показывает измеренные профили, число звёзд N и асимметрию A.
В ячейках `NO COMA` исходник сохраняется с плавным переходом. Локальные ядра интерполируются,
участки обрабатываются с перекрытием; обратный оператор использует отражённое асимметричное
ядро. В этом режиме «Сила 35/50/65%» — доля смешивания исходника с восстановленной
яркостью, а не уменьшение размера ядра. Проба и полный результат используют одну сетку.
RGB обрабатывается общей яркостью с сохранением соотношений каналов.

Перед применением и на всём результате проверяются: уменьшение моментной ширины ≥1%
и ≤35%, уменьшение асимметрии ≥2%, поток в пределах 5%, смещение центров ≤0,15 px,
рост шума ≤20%. В контрольных ячейках с ≥5 звёздами отдельно проверяются асимметрия и шум.
Это частичное восстановление умеренных хвостов в пределах измеренного окна, а не
восстановление сильной комы, длинных крыльев, дискового дефокуса или отдельных цветовых PSF.

## Криволинейный градиент фона

После сшивки нажмите **«Градиент фона…»**. Это отдельная аддитивная операция над результатом.
На сетке 20×20 берутся медианы небольших участков. Робастный отсев подавляет звёзды и
локальные яркие структуры; общая маска проб применяется ко всем каналам RGB.
Щелчком по ячейкам слева исключите туманности и галактики из оценки, затем нажмите
«Пересчитать». Зелёные отметки — принятые пробы, жёлтые — автоматический отсев или
отсутствующие данные, красные — ручные исключения. Маска влияет на оценку фона;
коррекция по поверхности применяется и под замаскированными объектами.

Для каждого канала сравниваются плоскость и квадратичная поверхность из шести коэффициентов.
Каждая пятая проба не участвует в обучающей подгонке. Кривизна принимается, если медианная
ошибка на оставшихся после отсева проверочных пробах уменьшается минимум на 10% и на 0,000001.
В противном случае используется плоскость. Если значимого градиента в канале нет, канал
сохраняется. Нужно ≥60 принятых проб, ≥10 в каждом квадранте, ≥10 проверочных проб.
Если значимый градиент не подтверждён ни в одном канале, применение недоступно.

Справа доступны модель и результат с общей с исходником растяжкой. Карта модели показывает
канал L/R: красная компонента вычитается, синяя добавляется; коэффициенты RGB независимы.
Вычитается поверхность за вычетом её медианного уровня на принятых пробах. Нули покрытия
сохраняются, нечисловые отсчёты заменяются нулём, отрицательные значения не обрезаются.
Применение явное; «Отменить» во вкладке результата возвращает предыдущий шаг.

Плавный протяжённый объект может быть неотличим от светового градиента по одному кадру.
Автоматический отсев не гарантирует его защиты: исключите объект и проверьте вычитаемую модель.
Инструмент не измеряет абсолютный фон неба и не исправляет мультипликативное виньетирование.
Для более сложного плавного фона доступна RBF-модель, описанная ниже.

## Нелинейный поперечный хроматизм

При хорошем покрытии поля радиальная добавка автоматически сравнивается с аффинной
моделью отдельно для R/B. Нужны ≥80 обучающих звёзд, ≥8 ячеек 4×4 с ≥3 звёздами,
≥10 звёзд в каждом квадранте, ≥20 на периферии. Каждая пятая звезда отложена;
усложнение принимается при уменьшении медианной ошибки ≥10% и >0,03 px.
Итоговые коэффициенты оцениваются по всем звёздам. Добавка ограничена по величине.
«Коррекция / остатки» переключает карту на ошибки на отложенных звёздах отдельной
обучающей модели; чёрные области не содержат проверочных проб. Это не ошибка итоговой
подгонки на тех же данных. Подписи показывают выбранную модель и проверочную ошибку.

## Виньетирование и чувствительность: master flat

Кнопка **«Master flat…»** загружает один калиброванный flat для всех исходных плиток.
Нужны те же оптика, фильтр, ориентация детектора и размер изображения; flat должен быть
заранее очищен от bias/dark. Поддерживаются один канал для всех каналов исходника либо
совпадающее число каналов. Для разных оптических конфигураций калибруйте кадры отдельно.
«Без flat» отключает коррекцию; после изменения пересшейте/обработайте результат.

Flat нормируется медианой отдельно по каналам и применяется до совмещения каналов,
оценки PSF и сшивки. Исходные файлы сохраняются. Допустимая нормированная чувствительность
0,2…5; плохие отсчёты маскируются нулём сразу во всех каналах. При >1% плохих пикселей
flat отклоняется. Отрицательный сигнал сохраняется. Без master flat виньетирование
не оценивается по одному фону: оно неоднозначно с яркостью неба/объектов.

## Отдельные цветовые PSF и эмпирический профиль

На экране деконволюции **«Цвет: отдельные PSF»** оценивает и восстанавливает R/G/B
независимо. Доступны общая гауссова, локальная эллиптическая, кома и эмпирическая модели.
Это позволяет частично исправлять продольный хроматизм и разное размытие каналов.
Каждый канал должен пройти свои проверки ширины, потока, центров и шума;
защитная маска насыщения/пропусков общая. На карте PSF можно переключать канал.
В отличие от обработки общей яркости, попиксельные отношения цветов здесь меняются;
по умолчанию сохраняется прежняя обработка общей яркости.

Режим **«PSF: эмпирическая 33×33»** складывает профили изолированных звёзд без требования
асимметрии. Он предназначен для умеренных негауссовых крыльев и дискового дефокуса
в пределах окна. Перед построением каталога применяется мягкое сглаживание, чтобы
умеренно плоские ядра не распадались на несколько обнаружений. В ячейке нужно ≥12 звёзд;
на отложенной трети эмпирический профиль должен быть лучше гауссова с той же ковариацией ≥5%.
Нужно ≥4 ячеек в ≥2 рядах/столбцах. Сила — смешивание восстановленного сигнала с исходником.
Проверяется моментная ширина вместо FWHM гауссова приближения; при исходной асимметрии
≥0,04 требуется её уменьшение, также проверяются локальные ширина/шум, центры и поток.
Сильный дефокус и потерянные пространственные частоты достоверно восстановить невозможно.

## Пространственное согласование PSF перед смешиванием

Включите «Согласовать резкость» и выберите **«PSF: поле/профили»**. Эмпирические профили
33×33 измеряются во всех 16 ячейках каждого канала каждой плитки. Нужны ≥12 изолированных
звёзд на ячейку и стабильность профиля на отложенной трети (L1-ошибка ≤0,15).
Положительные нормированные ядра 17×17 подбираются к общей круглой цели в пикселях мозаики.
Полный локальный якобиан геометрии учитывает масштаб, поворот и сдвиговую деформацию.
Цель начинается с 1,15 от максимальной большой оси σ с малым запасом, при необходимости
расширяется ещё в 1,18 раза до двух раз; предел — 14 px эквивалентной ширины мозаики.

Разрешение снижается, зато согласуются и меняющиеся по полю, и умеренно асимметричные
профили. Ядра интерполируются; перекрывающиеся участки плавно смешиваются, нули покрытия
сохраняются. Ошибка подбора полной PSF ≤0,08, смещение ядра ≤0,1 px. После пробы проверяются
ширина (≤8% от цели), профиль (L1 ≤0,15), покрытие каждой ячейки контрольными звёздами и
медианный поток (≤3%). Неудача отменяет согласование всего набора. Сведения — в диагностике.
Базовый режим «PSF: ядра» остаётся более быстрым вариантом для однородных почти гауссовых ядер.

## RBF-поверхность фона

В «Градиент фона…» выберите **«Поверхность: RBF»**, исключите объекты и пересчитайте.
Используются 25 широких гауссовых базисов с регуляризацией и квадратичной составляющей;
узкие интерполяционные пики не строятся. Нужно ≥120 принятых проб, ≥20 в каждом квадранте,
≥15 проверочных. RBF выбирается на канал только при уменьшении проверочной ошибки
относительно квадратичной поверхности ≥10% и >0,000001; иначе сохраняется простая модель.
Для вычисления полного результата поверхность представлена плавной сеткой 65×65 с
билинейной интерполяцией. Просмотр, ручные исключения, сохранение медианного уровня,
явное применение и отмена работают так же. RBF тоже может поглотить протяжённый объект:
ручная защита и проверка модели необходимы.

## Просмотр результата и сравнение

После применения улучшений на вкладке «Результат» по умолчанию включается
**«До / После результата»**. Вертикальная граница начинается в центре; тяните её
левой кнопкой мыши. Слева — исходный результат до всех улучшений, справа — текущий.
Исходная версия сохраняется независимо от ограничения истории отмены в три шага.
Кадрирование, поворот и отражение применяются к обеим версиям, чтобы сравнивался
один участок. Новая склейка или обработка одной плитки создаёт новую исходную версию.

В парных просмотрах деконволюции, цветных ореолов и градиента перемещение и масштаб
синхронизированы: управляйте любой стороной. Колесо меняет масштаб; в результате
перемещение — правой или средней кнопкой, поскольку левая используется для рамки
и границы сравнения. **«100%»** показывает исходный пиксель в одном экранном пикселе,
**«Вписать»** возвращает общий вид; эти кнопки работают и в парных просмотрах.

При увеличении результата и обзорных сравнений видимый участок берётся из исходных
float-пикселей, а не из растянутой миниатюры. Уменьшенный общий вид усредняет исходные
пиксели вместо пропуска строк и столбцов. Обе стороны используют одну растяжку,
рассчитанную по версии «До»; перемещение не меняет яркость. Это изменения просмотра,
точность обработки и сохраняемых научных данных не снижается.

## Цветные ореолы звёзд

После получения результата нажмите **«Цветные ореолы…»**. Для одного FITS/XISF сначала
загрузите его как единственную плитку и нажмите «Обработать». Инструмент предназначен
для линейного RGB, в котором центры каналов уже совмещены, а радиальные профили ядер
и крыльев различаются. Авторастяжка влияет только на отображение.

Сила по умолчанию 75%; доступны 50/75/100%. После изменения силы нажмите «Пересчитать».
Сравните «До/После» с общей растяжкой, затем «Применить к результату». «Обзор / участок»
переключает масштаб просмотра; для другого участка выделите область на вкладке
«Результат» и пересчитайте. Применяется ровно предварительно рассчитанный результат;
есть обычная отмена. Исходный файл не перезаписывается.

В каждом канале отдельно подбирается положительная смесь семи гауссовых профилей
с σ=1…8 px на фоне локальной плоскости. Половина пикселей отложена для проверки модели.
Общая цель — средний нормированный профиль RGB конкретной звезды, без требования белого
цвета. К исходнику добавляется разность моделей с плавным спадом на радиусах 18–22 px;
суммарный поток каждого канала сохраняется, измеренный остаток изображения остаётся.
Это локальная коррекция модели звезды: ядро одного канала может стать немного шире,
другого — уже. Она не восстанавливает потерянные детали протяжённых объектов.

Требуются SNR пика ≥60 и расстояние центров RGB ≤0,35 px. Насыщенные/слабые звёзды,
пропуски, заметные соседи ближе 50 px и плохие радиальные модели пропускаются.
Проверяется уменьшение измеренного расхождения профилей ≥10%, сдвиг центра ≤0,03 px,
ограничение поправки и отсутствие новых глубоких провалов. Вне принятых звёзд пиксели
не меняются. Сложная туманность под звездой может мешать оценке — просмотрите результат.
Инструмент не предназначен для больших отражений фильтра, сильной комы, тесных пар
и уже нелинейно растянутых файлов.

## Отчёт качества и предложения

После получения результата откройте **«Отчёт качества…»**. Отчёт сравнивает исходный
результат до улучшений с текущим, включая применённые коррекции; рассчитанные пробы
без применения не учитываются. После изменения результата отчёт пересчитывается при
следующем открытии. Кнопка «Пересчитать отчёт» обновляет измерения вручную.

Показываются изменённая площадь, карта 40×40, FWHM и эллиптичность ядер, смещение
центров RGB, расхождение радиальных профилей, оценка шума и изменение суммы сигнала.
Контроль — до 400 ярких изолированных ненасыщенных звёзд, измеряемых в обеих версиях.
Общая выборка и звёзды с изменениями в окрестности показаны отдельно. Графики:
карта затронутой площади, ширина ядер до/после, средние радиальные профили по каналам,
точки расхождения RGB до/после. Прокрутите отчёт вниз к графикам и рекомендациям.

Предложения зависят от остаточных измерений: сначала совмещение центров, затем
проверка цветных ореолов; при вытянутости — диагностика формы PSF. Рост оценки шума
более 20% вызывает предложение ослабить коррекцию и отменяет совет усилить резкость.
Для выводов о звёздах нужны ≥20 общих измерений. Применение предложений остаётся ручным:
они не определяют однозначно физическую причину размытия. Градиент требует защиты
туманности, а виньетирование — подходящего master flat.

Изменённая площадь не означает процент улучшения. Сумма сигнала всего кадра включает
фон и не заменяет звёздную фотометрию; шум по соседним пикселям зависит и от структуры.
FWHM описывает ядро, профили ограничены радиусом 16 px. Совмещение и сшивка,
предшествовавшие исходному результату, оцениваются отдельно в диагностике поля
и карте хроматизма. Единого «балла качества» нет; нулевой эффект и ухудшения сохраняются
в отчёте.

## Шумоподавление, детали и регуляризация

Откройте **«Шум / детали…»** после получения результата. Основной метод **Starlet**
встроен в приложение: B3-spline à trous без прореживания, четыре масштаба, оценка шума
отдельно по каналу и масштабу. Слабые коэффициенты плавно ослабляются; усиление деталей
применяется только к коэффициентам, превышающим шум. Начальная сила 50%; доступны
0/25/50/75/100%. Для деталей 1–2, 2–4, 4–8, 8–16 px доступны множители
1/1,1/1,25/1,5/0,75. Начните с уменьшения шума и единичных усилений.

«Пересчитать пробу» показывает участок до 768×768 из центра выделения либо изображения.
«После / удалённый сигнал» показывает разность До − После: серый — ноль, края диапазона
±4σ каждого канала. Заметные звёзды и волокна в разности требуют ослабить обработку.
Отображение разности не меняет научные данные. Панели синхронизированы. После изменения
параметров применение требует новой пробы. «Применить» обрабатывает полный результат;
доступны отмена, сравнение с исходником и отчёт качества.

Starlet сохраняет отрицательные линейные значения и исходные пропуски/нечисловые данные;
области насыщения и пропусков защищены. Обработка выполняется ограниченными блоками
с контекстом 30 px, до четырёх параллельных рабочих потоков. Одинаковая модель шума и
привязка блоков обеспечивают совпадение пробы и полного результата. Авторастяжка остаётся
только отображением. Данные с drizzle/дебайеризацией могут иметь коррелированный шум:
оценка по масштабам не гарантирует сохранение слабых объектов, проверяйте разность.

### Siril NL-Bayes и GraXpert

В том же инструменте можно выбрать внешний **Siril NL-Bayes** или **GraXpert**.
Приложения и модели в комплект не входят. Ищутся стандартные установки Windows и PATH;
для другого пути задайте ASTROMOSAIC_SIRIL или ASTROMOSAIC_GRAXPERT.
GraXpert запускается на CPU с уже установленной локальной моделью ONNX; отсутствующая
модель вызывает сообщение вместо автоматической загрузки. Параметры деталей действуют
только для Starlet. Внешние процессы ограничены 15 минутами, работают во временной папке,
исходный файл не перезаписывается; проверяются размерность и конечность результата.

**«Сравнить методы»** запускает три метода на одинаковых четырёх участках 256×256:
низкая, средняя, высокая медианная яркость и яркая звезда. Это кандидаты по яркости,
а не достоверная разметка фона/туманности. Показаны оценка шума, FWHM при наличии
контроля, сумма сигнала участка с фоном, число контрольных звёзд и время. Отсутствующие
программы отмечаются отдельно. Одинаковое числовое значение силы не означает одинаковое
сглаживание у разных методов; меньший шум сам по себе не означает лучшее изображение.
Сравнение не применяет результаты к изображению.

### Регуляризация деконволюции

Флажок **«Starlet-регуляризация»** добавляет мягкое двухмасштабное подавление слабых
коэффициентов после каждой итерации Richardson–Lucy. По умолчанию включён в новой сессии.
Контекст пробы расширен с учётом поддержки регуляризации. Это собственная ограниченная
реализация разреженной проекции, а не порт пакета STARRED. Все существующие проверки
пробы и полного результата продолжают действовать. Можно переключить «После / удалённый
сигнал»; для деконволюции разность включает перераспределение сигнала при повышении
резкости и не обязана выглядеть чистым шумом.

Отчёт качества дополнен RMS коэффициентов и графиком по четырём масштабам, измеренными
в одинаковых 16 участках до/после. Эти показатели включают и структуру, и шум.
Изображение удалённого сигнала доступно в инструментах, а не только общий числовой балл.
Без независимого эталона нельзя доказать достоверность восстановленных деталей.

Источники методов: [Siril: noise reduction](https://siril.readthedocs.io/en/latest/processing/denoising.html),
[Siril: à trous](https://siril.readthedocs.io/en/stable/processing/atrouwavelets.html),
[GraXpert](https://github.com/Steffenhir/GraXpert),
[STARRED](https://cosmograil.gitlab.io/starred/).

Отчёт также показывает применённые операции текущей сессии с именем метода и
параметрами шумоподавления/деконволюции. Отмена возвращает соответствующую историю.
Эта история пока не сериализуется при сохранении и повторном открытии файла.

## Левая панель и безопасный пересчёт

Управление перенесено в левую панель со сворачиваемыми разделами: файлы и запуск,
просмотр, параметры склейки, диагностика, улучшения результата, кадрирование/геометрия.
Параметры выбранного инструмента находятся в отдельном разделе сверху списка.
Список панели прокручивается независимо от изображения. Кнопки инструментов больше
не занимают верхние строки изображения. «Плитки» и «Результат» доступны постоянно.

Изменение PSF, совмещения каналов, LinearFit, выравнивания фона и перекрытия только
меняет настройки следующего расчёта. Автоматическая пересклейка отключена.
Нажмите «Склеить / Обработать» для явного запуска. Если есть кадрирование, улучшения
или выделение, панель предложит «Пересчитать из исходников» либо «Отмена пересчёта».
Подтверждённый расчёт заменяет результат и историю; при необходимости сначала сохраните
его. Простое изменение настроек сохраняет результат, исходную версию сравнения и отмену.

«PSF: ядра» — быстрое согласование гауссовой ширины почти круглых звёзд;
«PSF: поле/профили» — измеренные профили и пространственная сетка. Оба режима
согласуют более резкие данные с общей размытой целью перед сшивкой, а не увеличивают
резкость готового кадра. Не требуется каждый раз запускать оба режима.

### Поток при деконволюции

Проверка потока теперь использует круг радиусом 22 px с устойчивой локальной
плоскостью фона по кольцу 26–30 px. Маленькая апертура 8 px могла смешивать изменение
общего потока с его перераспределением в ядро. Допуск ±5% сохранён; в сообщении видны
фактическое отклонение, радиус и число фотометрических контрольных звёзд.

В круглой/эллиптической модели после ограниченных RL-итераций из поправки удаляется её низкочастотная составляющая
(нормированное симметричное гауссово сглаживание σ=3 px). Это ограничивает искусственный
прирост яркости при восстановлении деталей; контекст пробы расширен. Защитные маски
остаются, а фотометрия по общим звёздам всё равно проверяется. Проверка истинного
изменения потока не отключена. Эмпирические модели сохраняют полную поддержку PSF и прежний оператор восстановления;
они не используют эту дополнительную проекцию. Поток в них оценивается той же широкой
апертурой. Проба может законно не пройти другие проверки, например уменьшение ширины
менее 2%, недостаток звёзд или рост шума.
