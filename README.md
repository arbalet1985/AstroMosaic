# AstroMosaic

Сшивка астрономических мозаик (Windows, Go + Gio GUI).

- Раскладка плиток: по WCS, по номерам `R-C` в именах файлов/папок (как у ASIAIR) или по общим звёздам в перекрытиях.
- Привязка по звёздам с глобальной подгонкой и общей радиальной дисторсией; ручные точки для трудных пар.
- LinearFit (как в PixInsight) и выравнивание фона по перекрытиям (плоскость на плитку).
- Двухполосное смешивание: фон без звёзд плавно по всему перекрытию, детали — узким швом.
- Кадрирование и поворот результата; сохранение в FITS / XISF / TIFF / PNG / JPEG (линейные данные, растяжка только для просмотра).

## Сборка

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Скрипт собирает с `-trimpath` (без него Windows Defender ложно блокирует exe как `Bearfoos.A!ml`) и проверяет, что exe запускается.

Иконка и ресурсы Windows — в `winres/` (`go-winres make` после изменения).
